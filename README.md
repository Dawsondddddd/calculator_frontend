# 计算器系统 - 前端

前后端分离计算器系统的 Web 前端。只负责界面展示、用户输入、发送请求和显示结果，不做任何计算。

## 技术栈

- 原生 HTML + CSS + JavaScript（无框架、无构建步骤）
- `fetch` 调用后端 HTTP 接口

## 运行环境

- 任意现代浏览器（Chrome / Edge / Firefox）
- Python 3.8+（仅用于启动静态文件服务，也可以直接用浏览器打开页面）

## 安装方法

无需安装依赖。

## 启动方法

先启动后端（见 `backend/README.md`），然后任选一种方式：

方式一：用 Python 起一个静态文件服务

```bash
cd frontend
python -m http.server 5500
```

浏览器访问 <http://127.0.0.1:5500>。

方式二：直接用浏览器打开 `frontend/index.html`。

两种方式都可以，因为后端已经配置了 CORS。

> `127.0.0.1` 是本机回环地址，表示「这台电脑自己」。只有在本机把上面的命令跑起来、并且终端窗口保持打开时，这个地址才能访问；换一台电脑，或者把地址发给别人，都打不开。

## 常见问题

**浏览器提示「无法访问此网站」「127.0.0.1 拒绝了我们的连接请求」？**

说明 5500 端口上没有服务在运行。按顺序检查：

1. 在 `frontend` 目录下重新执行 `python -m http.server 5500`；
2. 保持这个终端窗口打开，输出里应出现 `Serving HTTP on 0.0.0.0 port 5500`；
3. 再访问 <http://127.0.0.1:5500>。

如果提示端口被占用，换一个端口启动，例如 `python -m http.server 5600`，然后访问 <http://127.0.0.1:5600>。

**页面能打开，但点 `=` 没有结果，提示「无法连接后端服务」？**

说明后端的 8000 端口没有启动。在 `backend` 目录执行 `python app.py`，确认输出 `Running on http://127.0.0.1:8000`，再刷新页面重试。

**为什么别人打不开 `http://127.0.0.1:5500`？**

`127.0.0.1` 永远指向访问者自己的电脑，不是你的电脑。要让别人访问，需要把前端部署到服务器或静态托管服务，并使用分配到的公网地址。

## 配置说明

后端地址在 `index.html` 的脚本开头：

```javascript
const API_BASE = "http://127.0.0.1:8000";
```

如果后端换了地址或端口，修改这一行即可。

## 前后端连接方式

| 操作 | 方法 | 接口 |
| --- | --- | --- |
| 点击 `=` 或按回车 | POST | `/api/calculate` |
| 页面加载、计算完成、删除后 | GET | `/api/history` |
| 点击某条记录的“删除” | DELETE | `/api/history/{id}` |
| 点击“清空历史” | DELETE | `/api/history` |

前端发送的是原始表达式（例如 `(1+2)*3`），计算结果完全由后端返回。停止后端服务后，前端仍可正常输入，但无法得到新的计算结果。

## 功能说明

- 数字与运算符按钮输入，支持键盘输入
- `C` 清空、`退格` 删除最后一个字符、回车计算、`Esc` 清空
- 显示后端返回的结果或错误信息
- 显示后端数据库中的历史记录
- 删除指定历史记录、清空全部历史记录
